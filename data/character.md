# 阿蕊 A-luí

「台灣人代表」的形象大使。這份文件只定必要的東西 ——
設定越細，她就越不可能同時是二十二個地方的代表。

## 名字

| | |
|---|---|
| 中文 | 阿蕊 |
| 台羅 | A-luí |
| 一般書寫 | A-Lui（帳號、檔名用，無變音符號） |

取自台語「一蕊花」。名字本身就在解釋她頭上為什麼永遠有一朵花。

不用 Rue：音雖近，但英文 rue 是「懊悔」的意思。

書寫時保留連字號與大寫 L：**A-luí**（正式）／**A-Lui**（無變音符號）。
不要寫成 Alui 或 alui。

## 她跟地方的關係

**這是整份設定最重要的一條。**

阿蕊是走遍二十二個縣市的人，不是任何一個縣市的在地人。

有了這條，「她在高雄」才成立，「她是高雄人」的爭議才不會發生。
一旦她有家鄉，其他二十一個縣市就都「不是她的」。

所以刻意**不設定**：家鄉、年齡、職業、身世、家庭。

## 髮上那朵花

她頭上永遠有一朵花。花的種類就是她所在縣市的**市花／縣花**。

- 花「永遠在」是恆定的識別記號
- 花「是哪一種」是地方變數

吉祥物的辨識靠剪影加一個不會認錯的記號，不是靠臉。
二十二個縣市有十八種不同的花，鑑別度足夠。

高雄是木棉花（紅色），跟通用白花差異明顯，一眼看得出換了地方。

**目前尚未實作。** 首頁維持一朵不指定的白花——首頁是台灣層級，沒有縣市可對應，
而且一旦戴上某一種特定的花，就會被讀成偏向某個地方。
「一朵沒有指名的白花」正好對應「不是任何一個縣市的在地人」。

另見 AGENTS.md 的「AI 畫不出植物學上正確的花」，那是落實這條規則前要先解決的問題。

## 恆定項與可變項

分界不是「臉以外都能改」，而是**造型能不能做到**。
綁法與配件是造型；髮色、髮長、眼睛顏色不是——剪了回不去，眼珠也不會自己換色。

| | 項目 | 說明 |
|---|---|---|
| **恆定** | 臉型與五官 | 辨識的基礎 |
| **恆定** | 眼睛顏色（褐色） | 換色等於換人。現有海報裡宜蘭是綠眼、花蓮是藍眼，那是生成瑕疵，要統一 |
| **恆定** | 髮色、髮長 | 造型做不到的事 |
| **恆定** | 頭上有一朵花 | 種類會變，但一定有 |
| 可變 | 髮型綁法、髮飾 | 這才是造型：草帽、花冠、串珠頭飾都算 |

**戴帽子時頭髮要放下。** 高馬尾配草帽會變成頭髮從帽子裡爆出來，物理上不成立。
澎湖第一版就是這樣——恆定項寫「髮型」、prompt 又要求照設定圖，兩者跟帽子打架。
恆定的是髮色與髮長，綁法本來就可變，有帽子就放下。

| 可變 | 服裝 | 款式、配色、在地元素 |
| 可變 | 手上的東西 | 該縣市的在地飲食或物產 |
| 可變 | 帆布袋與印花 | |
| 可變 | 背景與配色 | |

既有海報本來就在換造型，這是慣例不是新規則：

| 縣市 | 已經換掉的 |
|---|---|
| 台東 | 原住民族服飾、串珠頭飾 |
| 花蓮 | 手拿百合、串珠配件 |
| 宜蘭 | 手拿三星蔥 |
| 金門 | 軍綠色系、手拿高粱酒 |
| 連江 | 手拿馬祖老酒 |
| 桃園 | 粉色系穿搭 |
| 嘉義 | 草帽 |

原本二十張裡有十五張手拿珍奶、清一色白T加開襟襯衫，
那不是設定，是生成時偷懶的結果。要改。

**關於變色片**：曾考慮用「戴變色片」解釋眼睛顏色不一致，
並且花蓮的藍剛好是太平洋、宜蘭的綠剛好是蘭陽平原，說得通。
但不採用——阿蕊身上會變的東西已經夠多（衣服、髮飾、手持物、背景），
再讓眼睛也變，唯一不變的就只剩臉型，而那是張大眾臉。
真要玩，等系列站穩、大家已經認得她之後，當一次講明白的彩蛋。

## 兩個層級

| 層級 | 出現在 | 造型 |
|---|---|---|
| **台灣層級** | 首頁 | 通用版。她代表的是整座島，不是某個縣市，所以穿搭不指涉特定地方 |
| **縣市層級** | 第二段的縣市卡、分享圖 | 在地版。花、服裝、手上的東西、背景全部換成該縣市的 |

首頁那版不用改，它現在的通用造型是對的。
需要換的是二十二個縣市各自的版本。

## 每個縣市會變的

- **服裝**：款式、配色、在地元素（原民服飾、客家藍衫、討海人的條紋⋯）
- **手上的東西**：該縣市的在地飲食或物產。
  珍奶是全台共通的，屬於**首頁的台灣層級**，縣市層級不要再拿珍奶。
  高雄拿木瓜牛奶、宜蘭拿三星蔥、金門拿高粱酒——原始海報這幾張本來就做對了
- **帆布袋**：印花，或換成在地更合適的提袋
- **髮上的花**：該縣市的市花／縣花
- **背景**：地標與植物
- **配色**：整體色調

原本二十張裡有十五張手拿珍奶、清一色白T加開襟襯衫，
那不是設定，是生成時偷懶的結果。要改。

## 構圖（量自舊海報）

目視標定四張舊海報的人物外接框，取平均：

| | 佔畫面 |
|---|---|
| 寬 | 約 38% |
| 高 | 約 76% |
| 面積 | 約 29% |

也就是**人物至少佔畫面三分之一、大腿以上入鏡、貼近觀者**。
生成時人物變小是最常見的失誤，成因是參考圖用了全身立繪——
模型會連框取方式一起照抄。改用半身立繪 `ref-half.png` 並在 prompt 寫死數字。

## 說話的語氣

第一人稱，短句，像在傳訊息給朋友，不像導覽稿。

> 阿蕊今天在高雄。海風鹹鹹的，木瓜牛奶喝了兩杯。

避免：官方文宣腔、形容詞堆疊、驚嘆號連發。

**特別要避開競選口號的句型**：對仗工整、格局很大、但什麼都沒說。

原始海報上有兩段文字，品質差很多，**取對的那一段**：

| 位置 | 高雄的例子 | 判定 |
|---|---|---|
| 人物左側直排 | 海風鹹鹹，人情暖暖，高雄是咱的家 | ✓ 具體、有感官、像人在講話 |
| 左下信紙區 | 豪爽講義氣⋯擁抱世界、也照顧在地⋯讓世界看見我們的驕傲！ | ✗ 市政宣傳腔 |

判準很簡單：這句話換成任何一個縣市還成立嗎？成立的話就是空話。

## 不要做的事

- 不要說「阿蕊代表高雄人」——主詞用地方，不用人
- 不要給她家鄉
- 不要用各縣市的官方市徽（有使用規範），市花當視覺母題沒問題
