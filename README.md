# 台灣人代表

> 要動這個 repo 的話，先讀 [AGENTS.md](AGENTS.md)。

22 個縣市代表角色的展示站。單一 `index.html`，沒有建置步驟、沒有相依套件，
用瀏覽器直接開或丟任何靜態主機都能跑。

## 這個名字的意思

「代表」有兩種讀法，這個系列兩種都要。

**名詞的讀法**：一個角色，站出來代表這個地方。
**動詞的讀法**：這個地方的人，代表了某一種生活態度。

所以「台灣人代表」不只是「一個代表台灣人的角色」，
也是「台灣人代表了多元包容、創新進步、人情純樸、團結勇敢」。

同理，「高雄人代表」講的不是高雄人長什麼樣子，
而是高雄人代表了哪一種生活態度。市花、市樹、市鳥那些當然可以寫，
但它們是註腳，不是主詞。

台灣，不只是地理上的位置，更是一種生活的態度。

## 為什麼 22 張都是同一個角色

這是刻意的。角色固定，變的是她走到哪裡、身上帶著什麼。

換成 22 張不同的臉，等於宣稱「這就是某地人長的樣子」，
那是拿一張臉去代表幾十萬人。固定角色把命題換掉：不是「她是高雄人」，
而是「她在高雄」。地方性交給背景、穿搭與配件去承載——
沒有人會為了一朵木棉花吵架，但會為了一張臉吵。

## 本機預覽

```bash
cd /home/ct/taiwan-people
python3 -m http.server 8901
```

開 http://localhost:8901/

方形分享圖的下載功能用到 canvas，**必須透過 http 開**；
直接 `file://` 開會因為跨來源限制而失敗。

## 檔案

| 路徑 | 內容 |
|---|---|
| `index.html` | 整個網站，含資料表、地圖路徑與所有樣式 |
| `img/<縣市>.webp` | 20 張縣市代表海報 |
| `img/hero.webp` | 首頁人物（去背） |
| `img/hero-bg.webp` | 首頁背景手繪海景 |
| `img/logo.webp` / `logo-white.webp` | 毛筆 wordmark，深色版與白色版 |
| `img/terrain.webp` | 地圖的水彩地表材質 |
| `img/sea.webp` | 第二、三段的海面材質 |
| `img/deco-*.webp` | 海上點綴：海豚、帆船、海鷗、飛魚、燈塔小島、浪花 |
| `AGENTS.md` | **動這個 repo 之前先讀**：硬規則與驗證方式 |
| `data/character.md` | 角色阿蕊的設定：名字、她跟地方的關係、髮花規則、恆定項 |
| `data/counties.json` | 22 縣市資料表，`source` 欄位標可信度 |

## 改內容

`index.html` 裡的 `const R=[...]` 是唯一的資料來源，一個縣市一筆：

| 欄位 | 意思 |
|---|---|
| `n` | 中文縣市名（同時是地圖 `data-n`） |
| `en` | 海報下方的英文名 |
| `t` | 特質標語 |
| `s` | 圖檔 slug，對應 `img/<s>.webp`；留空就顯示佔位卡 |

新竹縣與新竹市、嘉義市與嘉義縣共用同一張海報：兩張圖的內容本來就橫跨縣市。

地圖路徑（`const MAP`）由 [g0v/twgeojson](https://github.com/g0v/twgeojson) 的
`twCounty2010.geo.json` 轉出，除非要換底圖否則不用動。

## 已知的資料問題

原始海報由 AI 生成，底部那排代表物**有錯**，不要直接抄進網頁：

- 高雄那張的「代表樹 鳳凰木」「代表鳥 黑面琵鷺」其實是**台南**的市樹與市鳥
- 「代表海產 石敢・櫻搏」不是詞

各縣市的市花／市樹／市鳥是官方指定的，有正確答案，要用就得逐一查證。
另外這組資料的鑑別度沒有想像中高：樟樹同時是苗栗、南投、雲林、台東的縣樹，
蝴蝶蘭同時是雲林、台南、台東的縣花，台灣藍鵲同時是台北、桃園、雲林的市鳥。
南投縣、嘉義市、金門縣則沒有指定縣鳥。
